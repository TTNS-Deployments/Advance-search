{% icon 'info' 16 %}How is the match % calculated?

Each document is scored by its best passage (text, or the caption and nearby text of an image).

  • Semantic ranker (normal case): the ranker's score, 0 to 4, shown as 0–100%.
  • Vector similarity (when the ranker is unavailable): how close the passage's meaning is to your query (cosine similarity), shown as 0–100%.
  • Exact match: a passage with your exact phrase scores higher. A code, file name, figure number or “quoted phrase” in your query only matches documents that contain it.

Only documents that really match are shown: those below {{ response.min_match_percent }}%{% if response.relative_cutoff_percent %}, or below {{ response.relative_cutoff_percent }}% of the best match,{% endif %} are hidden. The percentage is a relevance indicator, not a probability: compare results with each other rather than reading it as a certainty.
